## Overview

Waves Vocal Rider automatically rides vocal levels in real time, keeping vocals at a consistent level in the mix without manual gain automation, based on the mix bus level.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves Vocal Rider** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Auto Riding** | Real-time automatic gain riding based on vocal and mix bus analysis |
| **Sensitivity** | Adjustable response speed and sensitivity to level changes |
| **Write Automation** | Convert real-time riding to static DAW automation for editing |
| **Stereo Mode** | Process stereo or dual-mono vocal tracks independently |
